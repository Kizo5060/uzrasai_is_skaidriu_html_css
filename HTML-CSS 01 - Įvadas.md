# HTML ir CSS – Įvadas

## Tinklapių kūrimas

Tinklapių kūrime pradžiai susipažįstame su dviem pagrindinėmis technologijomis:

- **HTML**
- **CSS**

Jos naudojamos kartu, tačiau daro skirtingus dalykus.

---

# HTML

**HTML** – naudojamas tinklapio **struktūrai ir turiniui** sukurti.

Paprasčiau:

> HTML pasako, **kas yra puslapyje**.

Pvz. HTML pagalba galime sukurti:

- antraštes;
- tekstą;
- pastraipas;
- nuorodas;
- paveikslėlius;
- sąrašus;
- formas;
- mygtukus;
- puslapio dalis.

Pavyzdys:

```html
<h1>Mano puslapis</h1>

<p>Čia yra mano pirmas puslapis.</p>
```

Čia:

- `<h1>` – antraštė;
- `<p>` – pastraipa.

HTML pagrindinė paskirtis – sudėti puslapio **turinį ir struktūrą**.

---

# CSS

**CSS** – naudojamas kontroliuoti tinklapio **vizualinę išvaizdą**.

Paprasčiau:

> CSS pasako, **kaip HTML turi atrodyti**.

Su CSS galima keisti:

- spalvas;
- šriftus;
- teksto dydį;
- elementų dydį;
- tarpus;
- foną;
- elementų poziciją;
- išdėstymą;
- rėmelius;
- kampų apvalinimą;
- šešėlius;
- puslapio prisitaikymą prie skirtingų ekranų.

Pvz.:

```css
h1 {
    color: red;
}
```

Tai reiškia, kad visi `h1` elementai bus raudonos spalvos.

---

# HTML ir CSS skirtumas

| HTML | CSS |
|---|---|
| Kuria struktūrą | Keičia išvaizdą |
| Turinys | Dizainas |
| Antraštės | Spalvos |
| Tekstas | Šriftai |
| Paveikslėliai | Dydžiai |
| Nuorodos | Tarpai ir išdėstymas |

Galima įsivaizduoti taip:

**HTML = namo konstrukcija**

**CSS = namo dažai, baldai ir dizainas**

# Kaip vyksta mokymasis?

## Teorija

Pirmiausia aiškinamės:

- kas yra HTML;
- kas yra CSS;
- kaip veikia žymės;
- kaip veikia atributai;
- kaip sudarytas HTML dokumentas;
- kaip rašomas CSS.

## Live Coding

**Live Coding** – kai dėstytojas gyvai rašo kodą ir tuo pačiu aiškina, ką daro.

Svarbu ne tik nukopijuoti kodą, bet suprasti:

- kodėl jis taip parašytas;
- ką daro kiekviena eilutė;
- kas nutiktų ją pakeitus.

## Praktika

Po teorijos reikia pačiam rašyti kodą.

## Code Review

**Code Review** – parašyto kodo peržiūra.

Tikrinama:

- ar kodas veikia;
- ar naudojamos tinkamos HTML žymės;
- ar struktūra logiška;
- ar nėra nereikalingo kodo;
- ar CSS parašytas tvarkingai.
