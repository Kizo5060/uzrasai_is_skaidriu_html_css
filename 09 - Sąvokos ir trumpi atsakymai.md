# Sąvokos ir trumpi atsakymai

Šį lapą galima perskaityti prieš praktinį darbą, kad nereikėtų ieškoti kiekvienos sąvokos atskirai.

| Sąvoka | Paprastai |
|---|---|
| HTML | Puslapio struktūra ir turinys |
| CSS | Puslapio išvaizda |
| JavaScript | Elgsena ir interaktyvumas |
| Semantika | Tinkamų HTML žymių parinkimas pagal turinį |
| Selektorius | Taisyklė, nurodanti, kuriems elementams taikyti CSS |
| `class` | Klasė, kurią gali turėti keli elementai |
| `id` | Unikalus elemento identifikatorius dokumente |
| `margin` | Išorinis tarpas |
| `padding` | Vidinis tarpas |
| `border-box` | Plotis/skaičiavimai apima kraštinę ir padding |
| Flexbox | Išdėstymas viena pagrindine kryptimi |
| Grid | Išdėstymas eilutėmis ir stulpeliais |
| Responsive | Dizaino prisitaikymas prie ekrano dydžio |
| Media query | CSS taisyklės, taikomos pagal sąlygą, pvz., ekrano plotį |
| `:hover` | Stilius užvedus žymeklį |
| `::before` | CSS pseudo-elementas prieš elemento turinį |
| `object-fit` | Kaip vaizdas užpildo nustatytą vietą |
| CSS variable | Pakartotinai naudojama reikšmė, pvz., spalva |
| DRY | Nekartoti bereikalingai tų pačių kodo dalių |
| API | Būdas programai gauti duomenų iš kitos sistemos |

## Trumpi klausimai

**Kas svarbiau – HTML ar CSS?** Abu. Vertinama ir struktūra, ir panašumas į maketą.

**Ar galima viską daryti su `div`?** Techniškai galima daug ką išdėstyti, bet semantinei struktūrai geriau naudoti `header`, `main`, `section` ir kt.

**Ar būtinas JavaScript?** Pagal šį konkretų TECHIN HTML/CSS atsiskaitymo aprašą – neįvardytas kaip privalomas.

**Ar galima naudotis šiais užrašais atsiskaityme?** Pateiktame dokumente praktinėje dalyje leidžiama naudotis savo medžiaga. Tačiau reikia laikytis mokytojo taisyklių dėl kompiuterio, AI ir konkrečios užduoties.

**Ar užtenka, kad puslapis gražus?** Ne. Pagal PDF balai skiriami ir už HTML semantiką, CSS kokybę bei responsyvumą.
